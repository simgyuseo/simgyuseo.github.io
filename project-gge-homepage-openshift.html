[경기도교육청][홈페이지재구축프로젝트] OpenShift Cluster 기술지원 - 부사수

2025.05.09 ~ 2025.07.22

OpenShift
개요
  • 경기도교육청 홈페이지 재구축 사업에서 신규 서비스 인프라로 도입된 OpenShift Cluster의 운영 및 안정화 과정에 부사수로 참여하여 기술지원 수행.
역할
  • Helm chart로 배포된 디플로이먼트 메모리 리소스 제한 Request/Limits 설정 지원
  • 운영 내부망 CLUSTER에 Jenkins CI 도구 설치
  • 이슈 대응 및 트러블슈팅 지원(부사수역할): 특정 파드 "v2-6-istio-cni": Unauthorized 에러 로그 발생 및 ContainerCreating 상태 유지 문제 트러블슈팅
    • 해결 : 공식적으로는 OSSM 2.4 이상에서 해결된 사안이나 kubeconfig 파일의 인증 정보 갱신 실패 등 불안정 요소로 인해 OpenShift 4.16 클러스터 버전에서 발생할 수 있는 요소로 확인되었고 kubeconfig 인증 정보 갱신 후 istio-cni-node 파드 rollout으로 해결
  • 이슈 대응 및 트러블슈팅 지원(부사수역할): 특정 지역 교육청에서 L4 장비로 외부 접속자인 Client IP 대역과 OpenShift Cluster 내부 Pod CIDR IP 대역이 똑같아 서버가 외부로 응답을 못하고 클러스터 내부에서만 길을 잃고 무한루프가 발생한 상황
    • 해결 : 실제 해당 지역 교육청에서 Pod가 사용하는 CIDR IP 대역과 겹쳐서 통신이 되지 않는 상황이었으며 Infra Node에서 Layer4 Packet의 SRC에 Client IP가 직접적으로 노출됨을 확인. 정상적으로는 VIP가 노출되어야 하는 상황으로 해당 지역 교육청에서 트래픽이 유입되는 L4 장비에 SNAT(Source NAT 출발지 네트워크 주소 변환) 설정을 적용하여 Pod IP 대역과 겹치지 않도록 조치.
성과
  • Private OpenShift Cluster의 실무 안정적인 운영 경험 축적.
  • 실제 운영상에 발생하는 Pod 기동 시 에러 로그 및 OpenShift 플랫폼 네트워크 이슈 등을 트러블슈팅하며 안정적인 OpenShift 운영에 기여.
개선점
  • 대규모 OpenShift Cluster 운영 역량 보완을 위해 OpenShift 권장 아키텍처 직접 구성 및 Operator 설치 학습 진행 중 GitLab·Jenkins·ArgoCD·Harbor 기반 CI/CD 파이프라인 역량 확보 계획.
프로젝트 아키텍처 (Archify 스킬)
테스트 및 기술정리
