[한국기술교육대학][학사시스템] CentOS7.9 EOL로 인한 RockyOS 9.6 Apache/Tomcat/CLUSTER/APM 웹 시스템 재구축 프로젝트

2024.12.02 ~ 2025.01

Apache 2.4.33 Tomcat 8.5.54 Infinispan 13.0.21 OpenJDK 11 Rocky Linux 9.6
개요
  • 인프라 환경 이관: CentOS 7.9 EOL에 대응하여 Rocky Linux 9.6 VM 서버 기반의 신규 인프라 환경 수립.
  • 고가용성(HA) 아키텍처 구축: 학사 트래픽 분산을 위해 WEB 4대 - WAS 8대 구조의 로드밸런싱 설정 및 Infinispan 13.0.21(OpenJDK 11)을 이용한 세션 클러스터링(2대) 서버 연동.
역할
  • 인프라 엔지니어(RockyOS 9.6 VM 서버에 WEB 4대, WAS 8대, CLUSTER 2대, APM 1대 학사 웹시스템 설치 및 구성)
성과
  • 보안 및 운영 안정성 확보: EOL 대상 OS 이관을 통해 보안 취약점 리스크 제거 및 지속 가능한 오픈소스 운영 기반 마련.
  • 무중단 가용성 확보: 세션 클러스터링 환경 정밀 튜닝을 통해 특정 서버 다운 시에도 학사 서비스가 정상 유지되도록 가용성 극대화.
개선점
  • 미들웨어(Apache/Tomcat) 버전 선정만으로는 부족하며, OS → JDK → WAS → 애플리케이션 전 구간의 종속성·교차 호환성 사전 검증이 인프라 안정성의 핵심임을 확인.
  • 향후 인프라 설계 시 종속성·교차 호환성 사전 조사를 통한 시행착오 최소화 필요성 인식.
프로젝트 아키텍처(Archify 스킬: https://github.com/tt-a1i/archify)
테스트 및 기술정리
  • Apache httpd
  • Apache Tomcat
  • Session Cache (Infinispan / Redhat Datagrid)
