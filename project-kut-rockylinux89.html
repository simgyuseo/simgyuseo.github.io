[한국기술교육대학][학사시스템] CentOS7.9 EOL로 인한 RockyOS 9.6 기반 Apache HTTP Server/Tomcat/CLUSTER/APM 웹 시스템 재구축 프로젝트

2024.12.02 ~ 2025.01

Apache HTTP Server 2.4.33 Tomcat 8.5.54 Infinispan 13.0.21 OpenJDK 11 Rocky Linux 9.6
역할인프라 엔지니어 (WEB 4대·WAS 8대·CLUSTER 2대·APM 1대 학사 웹시스템 설치·구성)
핵심 성과EOL 리스크 제거, 서버 다운 시에도 로그인 세션이 유지되는 무중단 가용성 확보
① 문제 발견
  • 상황: 한국기술교육대학 학사시스템이 EOL 도래한 CentOS 7.9 기반으로 운영.
  • 문제: 보안 취약점 리스크와 함께, 학사 트래픽을 분산하고 특정 서버 장애에도 로그인 세션이 끊기지 않아야 하는 가용성 요구.
② 해결 방식
  • 이관: CentOS 7.9 EOL 대응으로 Rocky Linux 9.6 VM 서버 기반 신규 인프라 환경 수립.
  • HA 구성: 학사 트래픽 분산을 위해 WEB 4대 - WAS 8대 로드밸런싱 설정 및 Infinispan 13.0.21(OpenJDK 11) 세션 클러스터링(2대) 서버 연동.
  • 튜닝: 외부 세션 저장소 클러스터링 환경 정밀 튜닝으로 서버 다운 시에도 세션 유지.
③ 성과
  • AS-ISEOL 대상 CentOS 7.9 운영으로 보안 취약점 리스크 존재
  • TO-BEEOL 대상 OS 이관을 통해 보안 취약점 리스크 제거 및 지속 가능한 오픈소스 운영 기반 마련
  • TO-BE세션 클러스터링 환경 정밀 튜닝으로 특정 서버 다운 시에도 학사 서비스 로그인 세션이 유지되는 무중단 가용성 확보
④ 한계와 개선
  • 미들웨어(Apache HTTP Server/Tomcat) 버전 선정만으로는 부족하며 OS → JDK → WAS → 애플리케이션 전 구간의 종속성·교차 호환성 사전 검증이 인프라 안정성의 핵심임을 확인.
  • 향후 인프라 설계 시 종속성·교차 호환성 사전 조사를 통한 시행착오 최소화 필요성 인식.
⑤ 프로젝트 아키텍처 (Archify 스킬)
⑥ 테스트 및 기술정리
  • Apache httpd
  • Apache Tomcat
  • Session Cache (Infinispan / Redhat Datagrid)
