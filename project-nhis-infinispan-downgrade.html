[사회보장정보원][원내교육관리시스템] 런타임 JDK 11 환경 호환을 위한 In-Memory Data Grid:Infinispan13 버전 재구축 작업

2026.01

역할인프라 엔지니어 (JDK 11 환경에 맞는 외부 세션 저장소 Infinispan 서버 재구축)
① 문제 발견
  • 상황: 사회보장정보원 원내교육관리시스템의 런타임이 JDK 11 환경.
  • 문제: 외부 세션 저장소로 사용하던 Infinispan 7이 런타임 JDK 11과 호환되지 않아 In-Memory Data Grid 버전 정합성 확보가 필요.
② 해결 방식
  • 접근: 런타임 JDK 11 환경과 호환되는 In-Memory Data Grid:Infinispan 13으로 세션 저장소 서버를 재구축
  • 검증: WEB-WAS-IMDG-DB 계층 구조로 In-Memory Data Grid:Infinispan13 구축 후 WAS1번에 접속한 세션이 WAS1번 장애로 인해 WAS2번으로 요청이 갔을때 Failover 및 세션이 유지되는지 검증.
③ 성과
  • TO-BE런타임 JDK 버전에 맞는 세션 소프트웨어 버전을 설치하여 사용자의 세션 유실 없는 안정적인 서비스 환경 구축
④ 한계와 개선
  • WAS 단 세션 클러스터링을 구성해도 배포 애플리케이션(web.xml)에 <distributable/> 설정이 누락되면 정상 동작하지 않음을 트러블슈팅 과정에서 확인.
  • 이후 시스템 구축 시 인프라 관점에 한정하지 않고 애플리케이션 구조·요구사항까지 함께 검증하는 시야 확보 필요성 인식.
⑤ 프로젝트 아키텍처 (Archify 스킬)
⑥ 테스트 및 기술정리
  • Session Cache (Infinispan / Redhat Datagrid)
